# 给非技术用户的部署指南：域名、备案、正式版 App

> 本文面向不熟悉技术的使用者，用大白话讲清楚"怎么让 App 从"调试版"变成"正式版""。技术细节见 `deploy/RUNBOOK.md`。

## 一、先说清楚现在的状态

| 项目 | 现状 | 说明 |
|---|---|---|
| 服务器 | 阿里云 ECS（1.6GB 内存），IP `120.55.186.220` | 2026-08-14 晚因内存不足卡死，需在阿里云控制台"停止→启动"恢复 |
| App 调试版（v2） | 已做好 | 手机能装，但因为是"调试版"，部分系统会提示"来源不明"，且顶部有调试标记 |
| 网址 | 用的是 IP + 自签证书 | 浏览器会警告"不安全"，App 里已内置信任所以能用 |
| 正式版 App | 还没做 | 需要先有"域名 + 受信任证书"，否则装不上/连不上 |

**一句话**：现在的版本能用，但要变成"正式上线"，还差三步——① 域名；② 备案；③ 换正式证书。

---

## 二、第一步：买一个域名

域名就是网址的名字，比如 `doctorwang.cn`。

1. 在阿里云搜"域名注册"，选一个后缀（`.cn` 约 30 元/年，`.com` 约 60 元/年），下单购买。
2. 买完后在阿里云控制台找到"域名"列表，点"解析"（DNS）。
3. 添加一条记录：
   - 记录类型：`A`
   - 主机记录：`@`（代表裸域名，如 `doctorwang.cn`）或 `www`（代表 `www.doctorwang.cn`）
   - 记录值：`120.55.186.220`（你的服务器 IP）
   - 其他默认即可
4. 等 5~30 分钟生效。

> ⚠️ 重要：如果服务器坏了，域名也连不上——域名只是"门牌号"，服务器才是"房子"。所以**先修服务器，再绑域名**。

---

## 三、第二步：ICP 备案（大陆服务器必须）

因为你的服务器在**中国大陆**（阿里云），域名要指向它，就必须先做 **ICP 备案**（国家要求，实名制）。

- 在哪办：阿里云控制台 → 搜索"ICP 备案" → 按引导填资料（身份证、手机号、人脸核验）。
- 要多久：一般 **1~3 周**（阿里云初审 1-2 天 → 管局审核 1-2 周）。
- 费用：免费，但必须本人操作。
- 注意：**备案通过前，域名不能指向大陆服务器**（指向了会被阿里云拦截/封停）。所以正确顺序是：先备案，通过后再做 DNS 解析。

> 如果你不想等备案，另一个方案是买**香港/海外**的轻量服务器（免备案），但国内访问速度会慢一些、且仍建议备案。

---

## 四、第三步：申请受信任证书（免费）

备案通过、域名解析生效后，服务器上跑一条命令就能免费拿到证书（Let's Encrypt，90 天自动续期）：

```bash
sudo apt-get install -y certbot
sudo certbot certonly --standalone -d 你的域名 --email 你的邮箱 --agree-tos --no-eff-email
```

技术细节（证书路径、自动续期、改 Nginx 配置）都在 `deploy/RUNBOOK.md` 第 2 节，恢复脚本已预留。

拿到证书后，App 地址从 `https://120.55.186.220/` 换成 `https://你的域名/`，重新打包即可。

---

## 五、第四步：做正式版 App（发布到手机）

调试版能装，但正式发布（比如传到应用商店、或者直接发 APK 给朋友）建议用**正式签名包**：

1. 我这边会用正式签名（生成一个专属"钥匙"，类似房产证盖章）打包 release 版本。
2. 正式包的特征：没有"调试"字样、性能更好、不会被系统拦截安装（只要用户允许"安装未知来源应用"）。
3. 打包好后把 `.apk` 文件发给你，手机下载安装即可；后续有新版直接覆盖安装，数据不丢。

## 六、常见问题

**Q：我现在能用吗？**
能。服务器恢复后，下载调试版 v2 就能用全部功能（安心话聊、报告上传、AI 问诊）。

**Q：为什么浏览器打开提示"不安全"？**
因为现在是"自签证书"（相当于自己盖的章）。绑定域名+免费证书后，提示就消失了。

**Q：备案一定要做吗？**
大陆服务器+域名必须做。只想自己用、不发给别人，可以一直用现在的 IP 直连方案。

**Q：整个过程要多久？**
服务器恢复：10 分钟（你在控制台点几下）。域名：1 天。备案：1~3 周（最耗时，建议现在就申请）。证书：1 小时。正式版 App：半天。
