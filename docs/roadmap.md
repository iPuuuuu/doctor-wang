# Roadmap

## Phase 1: Harness Setup

- 补齐 `.ai/` 协作文档。
- 明确角色、流程、状态与决策记录。
- 让后续任务可以按统一工作流推进。

## Phase 2: Backend Foundation

- 稳定 Spring Boot 后端结构。
- 收敛 API 契约与测试。
- 为 AI 服务预留安全集成边界。

## Phase 3: AI Capability Layer

- 设计 RAG、Agent、Tool Calling 和 Evaluation。
- 建立可追踪的 Prompt / 模型 / 安全策略。

## Phase 4: Android Iteration

- 按统一协作流程推进页面、状态和体验优化。
- 保持与后端契约同步。

## Phase 5: Quality and Governance

- 建立回归、审查、决策和报告节奏。
- 让多 Agent 协作可持续。
