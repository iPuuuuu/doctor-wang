## 一、安装与登录（约 2 分钟）

- [ ] 浏览器打开下载链接，能下载并安装（提示"未知来源"时选"仍要安装"）
- [ ] 打开 App 能进登录页，界面正常显示
- [ ] 用 demo 账号登录成功，进入首页
- [ ] 首页能看到：AI 问诊 / 报告分析 / 安心话聊 三个入口

## 二、安心话聊（重点功能，约 3 分钟）

- [ ] 进入"安心话聊"，发送"我最近总担心自己得了大病，怎么办"
- [ ] 收到共情、有依据的回复（会引用 demo 账号里的报告内容）
- [ ] 回复底部有"报告原文"引用可展开
- [ ] 对话记录存在（退出再进还能看到历史）

## 三、报告查看（约 2 分钟）

- [ ] 进入"报告分析"，能看到 2 份报告（腹部超声报告 / 胸部X线报告）
- [ ] 点开"腹部超声报告"：有 AI 解析摘要、重点发现、建议
- [ ] 点"下载原文件"：文件能保存/打开（PDF 或图片，扩展名正确）
- [ ] 返回列表，数据正常

## 四、上传自己的报告（约 3 分钟）

- [ ] 点"上传报告"，选一张报告照片（或 PDF）
- [ ] 填写"检查类型"（如"血常规"）和"检查日期"
- [ ] 上传后状态变为"处理中"，稍等变成"已完成"
- [ ] 详情页出现 AI 解析摘要（说明 OCR 识别成功）
- [ ] 拍模糊的照片试试 → 应提示"报告内容需要人工复核"（诚实兜底，不瞎编）

## 五、AI 问诊与个人中心（约 2 分钟）

- [ ] "AI 问诊"里问"我有什么健康档案记录"，能得到基于档案的回答
- [ ] 个人中心能看到/修改资料
- [ ] 修改密码流程正常（改完用新密码能登录）
- [ ] 退出登录正常，再登录正常

## 六、异常与边界（可选，约 1 分钟）

- [ ] 断网时操作，App 提示友好错误而不是崩溃
- [ ] 上传非 PDF/JPG/PNG 文件 → 提示"仅支持 PDF、JPG、PNG"
